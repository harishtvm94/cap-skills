# CAP Get Started

Use this skill to initialize and run a Node.js CAP project.

## Workflow

1. Verify Node.js and npm.
2. Install the CAP CLI: `npm add -g @sap/cds-dk`.
3. Create a project: `cds init my-cap-app --add sample`.
4. Install dependencies with `npm install`.
5. Start locally with `cds watch`.
6. Inspect services and metadata through the generated OData endpoints.

Prefer the official CAP getting-started documentation and keep generated configuration minimal.
