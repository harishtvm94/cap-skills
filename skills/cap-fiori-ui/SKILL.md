# CAP Fiori and UI Integration

Expose CAP services for SAP Fiori elements and custom UI clients.

## Guidance

- Add UI annotations to service projections, not internal entities.
- Provide stable labels, selection fields, line items, and object page facets.
- Verify OData V4 metadata and draft behavior where applicable.
- Use generated service bindings and destinations consistently.
- Test navigation, actions, validation messages, and authorization from the UI.
