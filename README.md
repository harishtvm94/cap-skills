# CAP Skills

A practical skill library for building, testing, securing, and deploying Node.js applications with SAP Cloud Application Programming Model (CAP).

## Installation

Clone the repository and use the `skills/` directory with your supported skills workflow:

```bash
git clone https://github.com/harishtvm94/cap-skills.git
cd cap-skills
```

## Skill map

- `cap-developer` — central router
- `cap-get-started` — project initialization
- `cap-model-domain` — CDS domain modeling
- `cap-persistence-query` — persistence and CQN
- `cap-service-api` — services and OData
- `cap-handlers-transactions` — Node.js handlers and transactions
- `cap-validation` — validation and business rules
- `cap-testing` — automated testing
- `cap-security` — authentication and authorization
- `cap-fiori-ui` — Fiori/UI integration
- `cap-events-messaging` — events and messaging
- `cap-remote-services` — external services
- `cap-database-deployment` — database and deployment
- `cap-upgrade` — upgrades and migration
- `cap-assessment` — quality review

Additional examples and references are kept under the relevant skill directories. Consult the official CAP documentation at https://cap.cloud.sap/docs/ for current runtime and deployment details.
